# 🐶 OpenCaramelo
🌐 [**Site Oficial**](https://opencaramelo.com) • 📦 [GitHub](https://github.com/opencaramelo)

<img src="caramelo.png" width="300" alt="OpenCaramelo Banner">

🚀 **OpenCaramelo** é uma iniciativa voltada para disponibilizar **APIs abertas** com **dados públicos do Brasil**, de forma simples e gratuita dentre outros projetos. 😄  
Nosso objetivo é facilitar o acesso a informações como **CNPJ**, **CEP**, e outros conjuntos de dados públicos, para uso em **estudos**, **integrações** ou qualquer outro projeto que precise dessas informações.


---

### 📡 APIs disponíveis
- 🏢 **[Consulta de CNPJ](https://github.com/opencaramelo/opencnpj)** — dados de empresas registradas no Brasil.  
- 🏠 **[Consulta de CEP](https://github.com/opencaramelo/opencaramelo-cep)** — dados de endereços, cidades e IBGE.  
- 📊 *(Novas APIs em desenvolvimento...)*
